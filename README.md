# Luzel Tea

Premium D2C website for Luzel — an Indian chai brand.

```bash
npm install
npm run dev
```

The site is frontend-only and deploys directly to Vercel. The contact form
opens a prefilled email in the visitor's email app. Set `VITE_CONTACT_EMAIL`
in Vercel's environment variables to change the recipient; it defaults to
`hello@luzeltea.com`.

Replace photography in `src/content/site.js` when Luzel pack shots are ready. Legal pages are placeholders until policies are supplied.
